## [0.1.0] - unreleased

### Added
- Import edges from the Zig plugin carry `evidence_paths` and
  `evidence_lines`: the file and line of each `@import`.
- `examples/zig-clap/`, generated by `scripts/example.sh` from a pinned
  commit of Hejsil/zig-clap. CI checks that a rerun changes nothing.
- `scripts/release.sh` and `.github/workflows/release.yml`: reproducible
  archives for Linux and macOS (x86_64 and aarch64) with `SHA256SUMS`,
  published as a draft GitHub Release.
- `build.zig` accepts only the Zig version in `build.zig.zon` (0.15.1).

### Changed
- `zig build` compiles the plugins and Tree-sitter with Zig instead of the
  system `cc`, and installs them next to the binary.
- The binary loads plugins from `../lib/repo2mmd/plugins` relative to itself,
  so it works from any directory.
- `generate` writes to stdout by default, infers JSON from a `.json` output
  name, and honours `--cache-mode`.
- Output order no longer depends on the filesystem. Duplicate edges merge
  into one edge with all evidence. `manifest.generated_at` follows
  `SOURCE_DATE_EPOCH`.
- A file that cannot be parsed becomes a warning diagnostic instead of
  failing the run. Hidden directories, `zig-out`, and `node_modules` are not
  scanned.
- Mermaid node IDs no longer collide, edge labels use valid syntax, and
  modules such as `std` get readable labels.

### Fixed
- Output was cut off at a multiple of 4096 bytes because the writer was never
  flushed.
- JSON strings were not escaped.
- `@import("builtin")` and named modules resolved to nonexistent files.
- The TypeScript plugin wrote `typescript_debug.log` into the working
  directory and printed debug lines to stdout.

### Removed
- Committed binaries, cache files, machine-specific paths, scratch
  directories, template examples, and the copied Mermaid syntax docs.

### Added earlier in the 0.1.0 cycle
- Product plan baseline (`PLAN.md`) capturing problem statement, roadmap, and
  acceptance criteria for v0.1.
- Zig CLI scaffolding with `graph`, `explain`, `init`, and `cache` command
  stubs plus shared diagnostics/helpers.
- OpenCLI specification (`opencli.json`) describing the current CLI surface.
- Documentation set: architecture overview, IR schema draft, configuration
  guide, contributing/security guides, and examples fixture.

### Changed earlier in the 0.1.0 cycle
- Replaced template documentation with repo2mmd-specific README and policy
  updates.
- Removed legacy template automation from `.github/`.

## [0.0.1] - 2025-10-07

### Added
- Initial import from the C23 CLI template to seed Zig build, CI workflow, and
  repository structure.
